# Components

Live previews of the UI building blocks shipped with `@ghentcdh/crouton-vue`, grouped by purpose. Every example is interactive and comes with the snippet that produces it.

| Page | Components |
|------|------------|
| [Buttons, icons & menus](./buttons.md) | `Btn`, `BtnBadge`, `Icon`, `SubMenu` |
| [Form controls](./form-controls.md) | `Input`, `InputNumber`, `Textarea`, `Checkbox`, `SelectComponent`, `MultiSelect`, `Autocomplete`, `DatePicker`, `Markdown` |
| [Cards & layout](./cards.md) | `Card`, `Collapse`, `CollapseRow`, `Drawer` |
| [Tables & trees](./data.md) | `Table`, `TextCell`, `BooleanCell`, `PaginationComponent`, `TreeView` |
| [Modals](./modals.md) | `Modal`, `ConfirmModal`, `ModalService`, `ModalWrapper` |
| [Feedback](./feedback.md) | `Alert`, `Loading`, `Notifications`, `NotificationService` |

Import everything from `@ghentcdh/crouton-vue`:

```ts
import { Btn, Card, Input, Modal } from '@ghentcdh/crouton-vue';
```
