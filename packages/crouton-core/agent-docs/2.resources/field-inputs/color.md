# Color

Hex color (`#rrggbb`). Renders the native color picker next to a text input showing the hex value. Table cells and the view show a color swatch with the hex value.

```jsonc
"fieldInput": { "type": "color" }
```

The native picker only supports `#rrggbb` — no alpha channel or named colors.
